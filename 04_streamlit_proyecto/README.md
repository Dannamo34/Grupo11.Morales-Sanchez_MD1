# 04 - Dashboard Streamlit Pokémon

## 📌 Descripción
Este módulo visualiza los datos generados por el proceso ETL mediante un dashboard interactivo desarrollado con Streamlit.

---

## ⚙ Tecnologías utilizadas
- Python
- Streamlit
- Pandas
- Plotly

---

## 📂 Estructura

- dashboard.py → Aplicación principal
- requirements.txt → Dependencias
- data/ → Carpeta opcional

---

## ▶ Cómo ejecutar

Activar entorno virtual:

source venv/bin/activate

Ejecutar:

streamlit run dashboard.py

---

## 📊 Funcionalidades

- Visualización de estadísticas
- Filtros por nombre o tipo
- Tabla interactiva
