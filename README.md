# Proyecto ETL + Dashboard Pokémon

## 📌 Descripción General

Este proyecto implementa un proceso ETL utilizando la API pública PokeAPI y un dashboard interactivo desarrollado en Streamlit.

---

## 📂 Estructura del Proyecto

- 02_etl_proyecto → Proceso de extracción y transformación de datos
- 04_streamlit_proyecto → Visualización interactiva

---

## ⚙ Tecnologías

- Python
- Requests
- Pandas
- Streamlit
- Plotly

---

## 🚀 Flujo del Proyecto

1. Ejecutar el ETL
2. Generar el archivo CSV
3. Ejecutar el Dashboard
4. Visualizar datos interactivos
